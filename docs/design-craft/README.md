# Design craft (vendored)

Design rules and skills copied from [nexu-io/open-design](https://github.com/nexu-io/open-design) (Apache-2.0, see LICENSE-open-design). Skills keep their own upstream notes and licences in `.claude/skills/<name>/`.

- `.claude/skills/redesign-skill` — audit an existing UI for generic patterns and upgrade it without breaking it.
- `.claude/skills/taste-skill` — design-taste rules for premium interfaces.
- `.claude/skills/frontend-design` — distinctive, non-generic frontend direction.
- `.claude/skills/impeccable-design-polish` — final polish pass.
- `.claude/skills/design-review` — visual QA checklist.
- `docs/design-craft/*.md` — craft rules the skills refer to (anti-AI-slop, typography, colour, state coverage, laws of UX, accessibility, animation).
